# Dowsing Machine

## Un guide du format Expanded de Pokemon TCG

Dowsing Machine est un site de contenu sur le format Expanded de Pokemon TCG. Tu y trouves les pages d'archétypes avec leurs variantes et des deck lists d'exemple, la liste des cartes bannies avec la raison de chaque ban, les staples du format, et quelques pages éditoriales.

Les données des cartes viennent de TCGdex : chaque liste affiche les images, et il suffit de survoler le nom d'une carte pour la voir.

Le contenu est écrit par une petite équipe d'éditeur·ices. Les traductions passent par un circuit de relecture intégré au site, donc une page en français est relue par quelqu'un avant d'être en ligne.

## D'où ça vient

Le projet a démarré sous le nom d'Expanded Decks, un outil pour prêter des decks physiques aux joueur·euses pendant les événements. Les gens venaient pour les deck lists et les archétypes bien plus que pour les prêts. On a donc retiré la partie prêt en 2026 et fermé expandeddecks.app. Tout est maintenant sur dowsingmachine.com.

## Open source

Le code est open source sur GitHub : [github.com/jbourdin/dowsingMachine](https://github.com/jbourdin/dowsingMachine). Contributions, traductions et idées sont les bienvenues, ouvre une issue si tu as quelque chose en tête.

Dowsing Machine est un projet communautaire indépendant, sans lien avec The Pokemon Company.
