# Dowsing Machine

## A guide to the Pokemon TCG Expanded format

Dowsing Machine is a content site about the Expanded format of the Pokemon TCG. You'll find archetype pages with their variants and sample deck lists, the banned list with the reason behind each ban, and the staple cards of the format, plus some editorial pages.

Card data comes from TCGdex, so every list shows the card images and you can hover a card name to see it.

A small team of editors writes the content. Translations go through a review workflow built into the site, so a French page is checked by someone before it goes live.

## Where it comes from

The project started as Expanded Decks, a tool to lend physical decks to players at events. People came for the deck lists and the archetype pages much more than for the loans, so we retired the lending part in 2026 and closed expandeddecks.app. Everything now lives on dowsingmachine.com.

## Open source

The code is open source on GitHub: [github.com/jbourdin/dowsingMachine](https://github.com/jbourdin/dowsingMachine). Contributions, translations and ideas are welcome, so don't hesitate to open an issue.
